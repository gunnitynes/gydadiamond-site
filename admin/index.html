Paste your key to start. You only need to do this once on each computer or phone.

Where do I get a key?
  1. Sign in to GitHub and open github.com/settings/personal-access-tokens/new.
  2. Name it “Gyða website”, pick an expiry (up to a year), and under Repository access choose Only select repositories → .
  3. Under Permissions → Repository permissions set Contents to Read and write and Actions to Read and write.
  4. Click Generate token, copy it and paste it above.

The key stays in this browser only. Sign out on shared computers.
